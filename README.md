# Coleta10-unity
Minigame Coleta 10 é um projeto acadêmico em Unity 2D focado em movimentação e coleta de itens. O jogador utiliza WASD para mover o personagem, coletar 10 orbes e vencer a partida. O projeto foi desenvolvido em C# enxuto com New Input System (Invoke Unity Events), movimentação via Rigidbody2D e detecção por Collider2D.
